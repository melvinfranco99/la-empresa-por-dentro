# La empresa por dentro

Guía web práctica para informáticos sobre cómo se compone la infraestructura IT de una empresa, por niveles:

| Nivel | Tipo | Personas |
|---|---|---|
| N0 | Casa / autónomo | 1–3 |
| N1 | Microempresa | 3–15 |
| N2 | Pequeña empresa | 15–60 |
| N3 | Mediana empresa | 60–300 |
| N4 | Grande multisede | 300–5.000 |
| N5 | Multinacional global | 5.000+ |

Incluye fundamentos (cableado, fibra, IP, VLAN, DNS, Wi-Fi, rack, SAI), planos físicos y diagramas lógicos en SVG, hardware y software por nivel, problemas típicos con quién los resuelve (interno, operadora, fabricante, dirección), un asistente interactivo de diagnóstico, calculadoras (subredes, RAID, SAI, PoE, disponibilidad, climatización, ancho de banda, backup, coste de caída) y glosario.

Web estática sin dependencias: HTML + CSS + JS. Para verla en local basta con abrir `index.html`.

Los precios son orientativos (España/UE, 2026).
