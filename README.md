# La empresa por dentro

Guía web práctica para informáticos sobre cómo se compone la infraestructura IT de una empresa, por niveles:

| Nivel | Tipo | Personas |
|---|---|---|
| N0 | Casa / autónomo | 1–3 |
| N1 | Microempresa | 3–15 |
| N2 | Pequeña empresa | 15–60 |
| N3 | Mediana empresa | 60–300 |
| N4 | Grande multisede | 300–5.000 |
| N5 | Multinacional global | 5.000+ |

Incluye **★ Mi empresa** (caso real: edificio de 6 plantas, 24 APs, ~2.000 dispositivos Wi-Fi, vecinos: planos simulables de cada planta, plan de canales 3D, VLANs, capacidad, plan de Internet, switches EnGenius, GPO, problemas físicos/técnicos/éticos), **Wi-Fi a fondo** (ondas, dBm, canales, DFS, inSSIDer, Acrylic), **VLANs y subredes**, **Active Directory y GPO** y un **laboratorio** con simulador de radio (mapas de calor RSSI/SINR, contención cocanal, espectro tipo inSSIDer) y simulador lógico (VLSM, broadcast, DHCP, firewall).

Incluye también fundamentos (cableado, fibra, IP, VLAN, DNS, Wi-Fi, rack, SAI), planos físicos y diagramas lógicos en SVG, hardware y software por nivel, problemas típicos con quién los resuelve (interno, operadora, fabricante, dirección), un asistente interactivo de diagnóstico, calculadoras (subredes, RAID, SAI, PoE, disponibilidad, climatización, ancho de banda, backup, coste de caída) y glosario.

Web estática sin dependencias: HTML + CSS + JS. Para verla en local basta con abrir `index.html`.

Los precios son orientativos (España/UE, 2026).
